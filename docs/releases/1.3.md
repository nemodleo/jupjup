**Reports are now off by default.** Crash and usage reports only start if you turn them on (first-run window or menu). If you never turned them on yourself, 1.3 switches them off. Turning them off now also drops anything not yet sent.

**History keeps less.** Sign-in codes are no longer saved to History (the notification says *Not kept*), and codes saved by 1.2 are removed. The menu shows only how many items there are, not the latest text, so nothing shows up when you share your screen. Hover an item to delete just that one. History is excluded from Time Machine backups.

**Open at login, visible.** The first-run window now shows *Open at Login* so you can turn it off right there.

**Smaller fixes.** Dates like *2026 11 3* and page numbers like *1 2 3 4 5* are no longer joined as if they were codes. The update notice only opens download links from jupjup.d-t-it.com or this repository's GitHub releases.

**First launch:** Jupjup isn't notarized yet. After each update, open System Settings › Privacy & Security and click **Open Anyway** once more.

**오류·사용 통계는 이제 기본으로 꺼져 있어요.** 첫 실행 창이나 메뉴에서 직접 켜야 보내요. 직접 켠 적이 없다면 1.3에서 꺼져요. 끄면 아직 안 보낸 것도 버려요.

**기록이 덜 남아요.** 인증번호는 기록에 남기지 않아요(알림에 *기록 안 남김*이 보여요). 1.2에서 남은 인증번호도 지워요. 메뉴에는 최근 글 대신 개수만 보여서, 화면을 공유해도 지난 글이 비치지 않아요. 기록에 마우스를 올리면 하나씩 지울 수 있어요. 기록은 Time Machine 백업에 들어가지 않아요.

**맥을 켜면 함께 열기, 보이게.** 첫 실행 창에 *맥을 켜면 함께 열기* 줄이 생겨서 그 자리에서 끌 수 있어요.

**작은 고침.** *2026 11 3* 같은 날짜나 *1 2 3 4 5* 같은 쪽 번호를 인증번호처럼 붙이지 않아요. 새 버전 알림은 jupjup.d-t-it.com과 이 저장소의 GitHub 릴리스 주소만 열어요.

**처음 열 때:** 아직 애플 공증 전이라, 업데이트할 때마다 시스템 설정 › 개인정보 보호 및 보안에서 **그래도 열기**를 한 번 더 눌러 주세요.
